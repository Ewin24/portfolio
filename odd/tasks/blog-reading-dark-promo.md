# blog-reading-dark-promo

Objective: more AI essays, make the essays visible, a dark mode, a reading mode in the blog, and read marks that record when each article was read.
Branch: `feat/blog-reading-dark-promo`, one commit per unit. Delivery: stacked local commits; push, PR and merge only when Edwin asks. Runner: `npm run build`, `npm run test:routes`, `npm run test:newspaper`, `npm run test:xp`, `npm run test:disclosures`, plus the new drivers named below.

## Specs

- S1: "agrega mas articulos interesantes sobre ia". Each essay follows `skills/blog-essay-editor/SKILL.md` in full (no invented experience, every external claim sourced from a page read in the session, 1 to 3 figures, 1,200 to 1,800 words per language, `category: 'ensayo'`). Topics need Edwin's pick before drafting. Review markers must not reach a published page.
- S2: "tambien promocionalos de alguna forma para que sean visibles esos pensamientos". Assumption (no channel was named): promotion inside the site and through what the site emits, nothing posted to third-party accounts.
  - S2a A featured essays block on the home page, above the technical blog list, with its own heading, in both languages.
  - S2b An RSS feed `feed.xml` generated at build from `blogPosts`, linked from the page head.
  - S2c One static share page per post at `blog/<slug>/index.html` with that post's own title and description in Open Graph and Twitter tags, which sends a human visitor to `#blog/article/<slug>`. Today every shared link shows the generic site preview because routes are hash-based.
  - S2d Share controls on the article: copy link, LinkedIn, X. They share the S2c URL.
  - S2e An "Ensayos / Essays" quick filter in the blog filters.
- S3: "agrega el modo oscuro". A dark variant of the newspaper theme: same layout and type, dark paper and light ink, chosen from the header, remembered across visits, applied before first paint. With no stored choice it follows `prefers-color-scheme`. The light newspaper theme and the XP theme keep their current pixels.
- S4: "tambien un modo lectura en el blog". A toggle on the article that hides the site chrome (header, footer, recommendations, filters), centres a narrower column and lets the reader change text size; remembered across visits; Escape leaves it. Not offered in the XP theme.
- S5: "que quede marcado lo leido y cuando se leyó". A read article is visibly marked in the blog list and on the article itself, with the date it was read, in the reader's language. Marks already stored in a reader's browser (a plain list of slugs under `portfolio-read-posts`) must survive: they stay marked as read, without a date.
