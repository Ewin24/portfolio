# ai-case-studies

Objective: show in the portfolio the work that demonstrates practical use of AI, starting with two new case studies built only from verifiable evidence.
Branch: `feat/ai-case-studies`. Delivery: local commits; Edwin sees the result before any push ("cuando lo tengas me muestras"). Runner: `npm run build`, `npm run lint` (baseline 15 problems), drivers `test:disclosures`, `test:stack`, `test:typography`, `test:dark`, `test:xp`, `test:promo`, `test:newspaper`.

- S3 Case study "how I build software with AI agents" (point 1 of the proposal): "Reúne tus reglas de orquestación, los agentes de revisión, las habilidades que escribiste y la memoria entre dos equipos. Tiene datos propios: en ReaderSS, 44 pasadas de revisión con 47 hallazgos aplicados no encontraron los dos defectos que aparecieron al abrir el navegador, y hay 11 casos catalogados donde comentarios o casillas afirmaban algo que el código no hacía."
  - Constraint, authorship: the harness is mostly open-source tooling made by other people that Edwin installed and configured (the orchestrator rules and the receipt-driven review come from Gentle AI; Engram and CodeGraph are other people's tools). The case study says "I use", "I configured", "I adopted" for those, and "I wrote" only for what he wrote: the project skills in `skills/`, his own skills recorded in Engram, the browser drivers of this portfolio, the diagnosis of the memory sync. No tool is named as his own when it is not.
  - Constraint, evidence: every number comes from an Engram observation opened in full or from a file in this repository, and is recorded in the Log with its source. Where the outcome was bad (review missed what a user found; notes that claimed what the code did not do) it is told as such.
- S4 Case study "visibility to AI engines" (point 5): "Visibilidad ante motores de AI (este portfolio). La auditoría pasó de 58 a 83 sobre 100; hoy es una sola frase en un caso." Evidence: Engram #470, `public/llms.txt`, `public/llms-full.txt`, the pre-render and JSON-LD code in `vite.config.ts` and `index.html`.
- S5 Voice and confidentiality: titles and text follow `odd/tasks/plain-language-voice.md` (Edwin, 2026-11-18: plain human language, no slogan titles). `skills/business-data-protection/SKILL.md` applies. Nothing is quoted from a note that holds a credential.
- S6 Placement (assumption, "en automatico"): the lead case stays; the agent-workflow case becomes one of the two secondaries next to DevManager, so the first three cases a reader sees include two about AI; the visibility case is a brief. Datacredito moves to the briefs. Reversible by changing `order`.
- Claims to avoid, from the research: RAG, embeddings, vector search, fine-tuning, own evaluation suites, model training, cost figures, "prompt-injection defence".
- Not in this delivery: expanding the DevManager case (its published 862 API tests could not be confirmed from the notes read: they reach 399), the fintech document-extraction work (not live), changes to `src/content/experience.ts`.
